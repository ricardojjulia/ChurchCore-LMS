## Context

Seminaries, Bible colleges, and Christian high schools require rigorous, multi-criterion assessment frameworks for essays, sermons, exegesis papers, and practicum reports. Currently, ChurchCore LMS supports point-based grading and qualitative text feedback, but lacks structured grading rubrics.

Adding Rubric-Based Assessment fulfills accreditation criteria for higher education institutions while providing students with clear, transparent grading expectations.

---

## Council Positions & Architectural Guardrails

- **The Architect:** Rubrics should be attachable to any `assignment` or `graded_discussion` block. Teachers define criteria (e.g., *Biblical Exegesis*, *Theological Coherence*, *Clarity & Grammar*, *Practical Application*), score weights, and achievement performance levels (e.g., *Exemplary (4)*, *Proficient (3)*, *Developing (2)*, *Unsatisfactory (1)*).
- **The Engineer:** Embed rubric definitions within the block content JSON or a normalized `assignment_rubrics` table. Store student rubric evaluations in `submission_rubric_evaluations` linked to `block_submissions`.
- **The QA Lead:** Extend the Gradebook Grid (`COUNCIL-2026-030`) and Submission Review Modal to support one-click criterion scoring, auto-calculation of total scores, and PDF rubric summary export.
- **The Product Owner:** Provide pre-built rubric templates for common theological tasks (e.g., Expository Sermon Rubric, Hermeneutical Paper Rubric).

## Technical Specifications & Schema Plan

### 1. Rubric Schema
```sql
CREATE TABLE assignment_rubrics (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  org_id UUID REFERENCES organizations(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  criteria JSONB NOT NULL DEFAULT '[]'::jsonb, -- Array of { id, title, weight, levels: [{ points, description, label }] }
  created_by UUID REFERENCES profiles(uid),
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE submission_rubric_evaluations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  submission_id UUID REFERENCES block_submissions(id) ON DELETE CASCADE,
  rubric_id UUID REFERENCES assignment_rubrics(id),
  evaluator_id UUID REFERENCES profiles(uid),
  criterion_scores JSONB NOT NULL DEFAULT '{}'::jsonb, -- { [criterion_id]: { level_id, points, feedback } }
  total_score NUMERIC(5,2) NOT NULL,
  evaluated_at TIMESTAMPTZ DEFAULT now()
);
```

### 2. UI Surfaces & Workflows
- Rubric Builder modal in Course Editor (`src/components/builder/RubricBuilderModal.tsx`).
- Interactive Rubric Grader in Teacher Submission Review (`src/components/grading/RubricGrader.tsx`).
- Student Feedback View displaying rubric breakdown alongside submission comments.

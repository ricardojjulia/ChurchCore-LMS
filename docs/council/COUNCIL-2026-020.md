## Context

The daily factory reproduced eight failing legacy SQL suites on a fresh isolated
PostgreSQL 17 stack. Several tests use nonexistent roles/helpers, impossible
savepoints inside DO blocks, empty fixtures, stale policy names, or inaccurate
assertion plans. They cannot substantiate the security claims in their comments.
Inspection also found permissive legacy policies on content_pages and embeddings
that bypass tenant filters, unscoped SECURITY DEFINER group/concept readers,
auth/domain identity mismatches in group and semantic-search functions, and
repeated text from lax recursive JSONPath extraction. The npm audit reports 47
advisories including one critical Next.js advisory.

## Council Deliberation

- **The Architect:** Repair existing contracts with forward migrations; keep the
  signed OneRoster transport and standalone contract intact. Vote: Yes.
- **The Engineer:** Use deterministic transactional fixtures and real authenticated
  roles. Preserve current public signatures; keep runtime upgrades within supported major versions and verify test-tool major upgrades. Vote: Yes.
- **The Security Lead:** Explicitly approve removal of obsolete permissive policies
  and tenant/active-account checks in affected readers. Test denied cross-tenant,
  anonymous, suspended and nonmember requests plus allowed same-tenant flows. Vote: Yes.
- **The Product Owner:** Restore working course content, group discussions and
  semantic retrieval without adding a new feature or claiming M3 complete. Vote: Yes.
- **The QA Lead:** Do not replace failed behavior assertions with unconditional
  passes. Execute the full pgTAP, unit, E2E, lint, type, build and browser suites. Vote: Yes.
- **The Data Engineer:** Keep fixtures rolled back and historical migrations
  immutable. No cloud database writes in this run. Vote: Yes.

## Decision And Amendments

1. Repair the eight inherited SQL suites with explicit org/Auth/domain fixtures,
   actual PostgreSQL roles and exact assertion plans. Retain their behavioral intent.
2. Remove obsolete content/embedding policy grants that bypass tenant scoping;
   retain existing staff capabilities within an active tenant and enrolled-student
   published-content access. Inactive embeddings must never reach student search.
3. Scope group membership/discussion and related-concept reads to the caller's
   active tenant. Correct Auth versus domain UID use without changing identity storage.
4. Ensure tutor/search functions work for the existing Auth-based section
   enrollments, reject unauthorized actors, and preserve service-only data writes.
5. Correct duplicate TipTap text extraction without rewriting stored user content.
6. Update vulnerable runtime dependencies within supported major versions and upgrade the affected Vitest test tools together and verify peers;
   do not use forced or legacy peer resolution or lower coverage thresholds.
7. LMS only. Academy sender work and gradebook/REST milestones remain outside
   this repair. Existing release and architect-review gates remain in force.

LMS PR and wait for hosted checks; do not merge migrations without architect review.

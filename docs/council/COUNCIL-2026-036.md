## Context

ChurchCore LMS provides a Guardian Portal (`/guardian`) where parents and guardians monitor academic progress, attendance, and certificates for their linked students. While teachers can send general announcements, there is currently no direct, secure two-way communication channel between teachers and guardians regarding specific student enrollments.

Council Review 3 and ministry pilot feedback identified Teacher ↔ Guardian messaging as a top priority for K-12 Christian academies and youth ministry discipleship.

---

## Council Positions & Architectural Guardrails

- **The Security Lead:** Guardians must **only** be able to initiate direct threads with teachers who are actively assigned to a course or section in which their verified ward is currently enrolled. Cross-tenant and unverified student queries must be strictly rejected at the database RLS layer.
- **The Data Engineer:** Introduce thread categorization (`thread_type: 'guardian_inquiry'`, `ward_id: UUID`) linking the message thread directly to the student enrollment context.
- **The Architect:** Seamlessly integrate with the existing `useMessages` hook, realtime subscriptions, and the `send-guardian-notifications` Edge Function / Resend email bridge so offline teachers or guardians receive instant email alerts with unread message digests.
- **The Product Owner:** Provide dedicated "Message Instructor" buttons within the Guardian Portal student view and a "Guardian Conversations" filter within the Teacher Inbox.

## Technical Specifications & Schema Plan

### 1. Database Migration (`teacher_guardian_messaging.sql`)
- Add `context_type` (`'course'`, `'section'`, `'ward_inquiry'`) and `context_ward_id` (nullable UUID referencing `profiles.uid`) to `message_threads`.
- Add RLS policy:
  ```sql
  CREATE POLICY "guardians_message_active_teachers"
  ON message_threads FOR INSERT
  WITH CHECK (
    auth.uid() = created_by AND
    EXISTS (
      SELECT 1 FROM guardian_students gs
      JOIN course_enrollments ce ON ce.user_id = gs.student_id
      JOIN course_teachers ct ON ct.course_id = ce.course_id
      WHERE gs.guardian_id = auth.uid()
        AND ct.teacher_id = recipient_id
        AND gs.verified = true
    )
  );
  ```

### 2. UI Surfaces & Actions
- Server action `sendGuardianMessage(teacherId, wardId, subject, body)` in `src/app/actions/messages.ts`.
- Component `GuardianMessageModal.tsx` in `src/components/guardian/`.
- Updated Inbox view in `src/app/messages/page.tsx` with student context badge.
